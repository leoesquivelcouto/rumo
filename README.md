# rumo

Rastreador de candidaturas a estágio que também diz **o que estudar a seguir**: cadastre as vagas e
os requisitos, e o `rumo` mostra a compatibilidade de cada uma com as suas competências e quais
competências as vagas mais pedem e você ainda não tem.

> 🚧 **Em construção.** O projeto está sendo publicado em etapas: schema do banco, regras de
> compatibilidade, validação, API e interface, cada uma com seus testes.

**Stack:** Python · FastAPI · Pydantic · SQLite · pytest · Docker · GitHub Actions
